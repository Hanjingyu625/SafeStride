# jingyu 신호 조회 변경

20m 진입 시 현시와 잔여시간 API를 조회한다. 원본 타임스탬프와 잔여시간으로
종료 시각을 계산하고 그때까지 Raspberry Pi가 남은 시간을 계산한다.
예를 들어 원본 20초, 수신 지연 2초면 18초 뒤 다시 조회한다.
수신 시 오래된 데이터, 서로 다른 교차로, 현시/시간의 시각 불일치는 사용하지 않는다.
만료 뒤에는 새 응답을 기다리며 빨강에서 녹색으로 자동 전환하지 않는다.

빨간불 시간은 재조회 시각에만 사용하며 횡단 가능한 시간은 항상 0이다.
잔여시간이 없거나 36000/36001 등 사용 불가 값이면 최소 3초 간격으로 재시도한다.
429 대기와 서버 한도는 유지한다. 조회 한 번은 개별 API 두 건이다.

다른 방향 신호색을 비교하거나 합의시키는 처리를 제거했다.
선택된 횡단보도의 매칭 방향 한 개만 판단한다. 다른 신호가 빨강이어도
선택된 녹색을 무효화하지 않는다. 매칭 미확정이면 횡단보도 후보를 그대로
유지하면서 신호만 미확정으로 표시한다. 임의의 녹색을 골라 연결하지 않는다.

신호 응답 이후 예정 종료 전에 실제 현시가 변경되면 재조회 전에는 감지할 수 없다.
이 표시는 마지막 수신 정보의 카운트다운이며 실제 현장 신호 확인이 필요하다.
일일 전체 신호 주기를 예측하거나 저장한 시간표를 반복 실행하는 기능은 아니다.
기존 모터 출력 설정과 횡단 정책은 유지한다.

이 문서의 조회 방식은 SIGNAL_REALTIME_UPDATE_KO.md의 3초 정기 조회 설명을 대체한다.
