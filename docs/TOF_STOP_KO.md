# TOF-10120 장애물·낙차 감속 정지

## 적용 조건

- 센서 높이 442 mm, 수평에서 아래로 45°, 앞바퀴 맨 앞보다 75 mm 뒤.
- 평지 기준 광선 거리 약 625.1 mm. 기준 대비 광선 거리 약 353.6 mm 변화가 수직 높이/깊이 250 mm에 대응한다.
- 바닥에 대한 높이 추정이다. 단일 빔으로 장애물의 전체 형상이나 낙차 가장자리까지의 거리를 측정하지는 못한다. 경사·차체 피치 변화는 오검출에 영향을 줄 수 있다.
- 40 cm/15 cm 거리 판정 대신, 확정 감지 시 즉시 경고와 감속을 시작한다. 디스플레이 호출은 supervisor의 TODO 주석만 작성했다.

## 동작

ToF는 50 ms마다 읽고 EMA 필터와 4회 연속 임계값 초과로 RAISED/DROP을 확정한다. 초기 10회는 필터 준비 단계이며, 시작할 때 보이는 물체를 평지로 학습하지 않는다. 고정 기준을 사용하므로 느린 거리 변화도 학습으로 사라지지 않는다. 필터 지연은 입력 크기에 따라 달라진다.

확정 감지는 `/terrain/status`의 `tof_alert`와 `terrain_hazard`로 전달된다. supervisor는 프로토콜 v6의 `DriveCommand.TERRAIN_STOP=2`를 반복 발행한다. Drive MCU는 그 순간 실제 PWM을 저장하고 3초 동안 선형 감소시킨 뒤 PWM 0, IN1=IN2=LOW를 유지한다. 반복 명령은 타이머를 재시작하지 않는다. 회복 명령이 먼저 도착해도 시작한 3초 감속은 완료한다. 상위 우선순위 정지·통신 watchdog·핸들 해제는 기존 경로를 유지한다.

위험 해제는 유효한 NORMAL 측정이 0.5초 지속되고 최소 정지 시퀀스 시간이 지난 경우에만 허용한다. 재출발은 기존 목표속도 제어기로 복귀하며 정상 제어 출력에 도달할 때까지 PWM 증가를 초당 10 count로 제한한다. 이후에는 일반 20 count/s 증가 제한으로 복귀한다. PWM은 Arduino 0~255 척도의 count이며 기존 cap 100은 유지한다. 목표속도에 필요한 PWM은 속도 제어기가 결정한다.

센서 읽기 실패·범위 초과·준비 중 상태는 `/terrain/status`의 `tof_valid=false`, `tof_alert=TOF_INVALID`와 `/diagnostics` 경고로 표시한다. 이 상태만으로 새 정지를 시작하지 않는다. 단, 이미 확정된 위험은 읽기 실패로 해제하지 않는다. Terrain 보드 연결이 끊겨 MPU 데이터까지 사라지면 기존 IMU 제동이 별도로 동작할 수 있다.

## 활성화 및 배포

두 YAML의 `terrain_stop_enabled: true`가 기본값이다. 기존 `require_range_sensors`/`require_terrain_tof`는 이 기능의 활성화 스위치가 아니다. 비활성화하려면 `terrain_stop_enabled: false`를 사용한다. 표면 인식 제어 설정은 별개다.

새 명령의 혼용을 막기 위해 **Pi 소프트웨어 및 Drive Uno, Terrain Uno를 모두 프로토콜 v6 / schema 0x0601로 함께 갱신**해야 한다. ROS 메시지를 추가했으므로 Pi에서 `colcon build` 후 새 `install/setup.bash`를 source한다. 로컬 코드 수정은 보드 업로드나 서비스 재시작을 수행하지 않는다.

## 확인

1. 바퀴를 들어 올린 상태에서 평지 기준 측정이 약 625 mm인지 확인한다.
2. `ros2 topic echo /terrain/status`로 정상/장애물/낙차/측정 불가 상태를 확인한다.
3. 장애물·낙차 확정 시 `/drive/command`의 mode=2와 `/walker/status`의 PWM 감소, braking 상태를 확인한다.
4. 유효 NORMAL로 복귀하면 재가속을 확인한다. 위험 감지 후 센서를 가려 측정 불가로 만들어도 재출발하지 않아야 한다.
5. 위험이 없던 상태에서 ToF만 분리했을 때 진단만 발생하는지 확인한다. MPU까지 분리하는 시험과 구분한다.

로컬 테스트는 실제 거리 정확도, 전기적 브레이크 성능, 차량 정지거리를 검증하지 않는다.
